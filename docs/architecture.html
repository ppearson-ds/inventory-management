Filter System

Four global filters managed by useFilters.js composable (singleton pattern). FilterBar.vue binds to shared refs; all views watch for changes and re-fetch.

Time Period
?month=
all2025-01… 2025-12Q1-2025Q2-2025 Q3-2025Q4-2025
Warehouse / Location
?warehouse=
allSan Francisco LondonTokyo
Category
?category=
allCircuit Boards SensorsActuators ControllersPower Supplies
Order Status
?status=
allDelivered ShippedProcessing Backordered

Note: Inventory endpoints only support warehouse + category (no time dimension). Demand, Backlog, and Spending endpoints accept no filters.

Design System & Key Patterns

Colors
Slate / Gray palette
#0f172a dark · #64748b mid · #e2e8f0 light
Status Colors
Semantic status
Green=Delivered · Blue=Shipped · Yellow=Processing · Red=Backordered
Charts
Custom SVG
Donut & bar charts built with SVG viewBox — no charting library
i18n
English & Japanese
useI18n composable · Currency auto-switches USD / JPY · localStorage
State: useFilters.js singleton → all views share one filter state Modals: props-down / events-up pattern, v-if controlled by parent Reactivity: raw data in refs, all derived values in computed() Revenue goal: $800K/month single · $9.6M YTD all months
