Request Data Flow
Step by step
1
User changes a filter
FilterBar.vue updates a ref in useFilters.js
2
View reacts and fetches
A watch() fires; calls api.js with getCurrentFilters()
3
api.js builds the URL
Non-all filters appended via URLSearchParams
4
FastAPI filters in memory
apply_filters() + filter_by_month() on the in-memory list
5
Pydantic validates + serialises
Response validated against model, returned as JSON
6
Vue stores in a ref
allOrders.value = response — raw data kept intact
7
computed() derives display data
Aggregations, totals, chart data — cached until deps change
8
Template renders
v-for with unique :key (sku / id, never index)
